# HUD 插件测试台

用 jsdom + 真 React 在 Node 里模拟 DSH 的渲染环境，验证「侧栏会话行光效」全链路。

## 为什么要它

这套效果依赖三类信号：

1. `sessionStatus`（DSH 官方的 `running` 状态，经 slot props 下发）
2. 侧栏行的状态标签（"进行中 / 已完成"，始终渲染）
3. 本地状态机（回车 / 点击发送后立即进入思考态）

任何一处时序或分支写错，表现都是"效果不出来 / 不消失"，靠肉眼截图对照成本极高。
这个测试台把三类信号都模拟出来，**15 秒跑完 17 条断言**。

## 运行

```bash
cd packages/hud
pnpm add -D jsdom react react-dom
pnpm test
```

## 覆盖范围

| # | 场景 | 断言 |
| --- | --- | --- |
| 1 | 初始 | 不残留任何动态元素 |
| 2 | 会话开始运行 | 主环 + 反向副环出现且可见 |
| 3 | 5 秒后 | 切换为进度条、宽度合理、能量头跟随、行内扫光出现 |
| 4 | 两个会话同时运行 | 各自一套元素，互不干扰 |
| 5 | 会话结束 | 补满、带 `data-done`、元素被清理 |
| 6 | 全部结束 | 归零 |
| 7 | 兜底路径 | 回车启动 → 消息尾出现 → 补满 → 清理 |

## 结构

```
test/harness.mjs
  ├─ 构造假 DOM（侧栏行 / 输入框 / 消息尾）
  ├─ 桩 window.__ModuleLoader__，捕获插件模块
  ├─ 桩 ctx.slots，取得注册的座位组件
  ├─ 用 props.useSessionStatus 注入状态 Map
  └─ 翻转 running / 派发回车 / 追加 turnTail，断言覆盖层样式
```

## 注意

- 测试台会屏蔽 `fetch` 与 `Image`，避免向本地探针发送遥测；
- 如果新增视觉效果，**先在这里加断言**，避免回归。
